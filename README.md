# Primeiro Voto

Cartilha digital interativa do projeto de extensão **Primeiro Voto: Conhecimento, Cidadania e Participação Política**, da Universidade Católica do Salvador (UCSal).

## Tecnologias
- React 18
- Vite
- CSS responsivo
- React Hooks para as interações e o quiz

## Executar localmente
```bash
npm install
npm run dev
```

## Build de produção
```bash
npm run build
npm run preview
```

## Publicação
O projeto está preparado para deploy na Vercel. O Vite gera os arquivos de produção na pasta `dist`.

## Estrutura
- `src/App.jsx`: aplicação React e interações.
- `src/content.html`: conteúdo editorial da cartilha.
- `src/styles.css`: identidade visual, layout responsivo e animações.
- `src/main.jsx`: inicialização do React.
