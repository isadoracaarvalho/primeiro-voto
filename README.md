# Primeiro Voto

Cartilha digital do projeto de extensão **Primeiro voto: Conhecimento, Cidadania e Participação Política**.

## Tecnologias
- React
- Vite
- React Router
- CSS responsivo

## Executar localmente
É necessário ter Node.js instalado.

```bash
npm install
npm run dev
```

## Gerar versão de produção
```bash
npm run build
```

## Publicação
O projeto está configurado para publicação no GitHub Pages. Confira o nome do repositório em `vite.config.js` antes de publicar.

## Conteúdo
As páginas iniciais são uma estrutura de trabalho. Antes da publicação, revise e complemente o conteúdo com fontes oficiais da Justiça Eleitoral e com as referências previstas no projeto de extensão.
